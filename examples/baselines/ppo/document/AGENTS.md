# Paper Writing Preferences

Use these preferences when drafting or revising paper text in this directory.

## Structure
- Keep the main manuscript in `main.tex`.
- Keep bibliography entries in `refs.bib`; do not inline bibliography items into the paper draft.
- Prefer editing the existing draft rather than spawning many parallel `.tex` variants unless explicitly requested.

## Style
- Write concisely. If unsure, compress rather than expand.
- Avoid survey-note prose that reads like a literature dump.
- Favor short paragraphs with clear argumentative roles.
- Make the paper sound intentional and selective, not exhaustive.
- Use [arXiv:2504.04939](https://arxiv.org/pdf/2504.04939) as the closest writing-style reference mentioned by the user.

## Related Work
- Start from a clean taxonomy or grouping, then place representative papers inside each bucket.
- Emphasize positioning over coverage.
- End each subsection by stating the paper's specific difference from prior work.
- Prefer representative citations over long enumerations when the extra papers do not sharpen the argument.
- Avoid Claude-like verbosity, repeated framing, and padded transitions.

## Collaboration Notes
- The user is sensitive to writing aesthetics and dislikes text that is technically correct but stylistically bloated.
- When revising generated prose, tighten wording first before adding more citations or explanation.
